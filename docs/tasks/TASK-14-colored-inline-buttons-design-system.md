# TASK-14: Цветные инлайн-кнопки (Bot API 8.0+ style) и дизайн-система

## 1. Контекст и возможности Telegram Bot API
В актуальных версиях Telegram Bot API для `InlineKeyboardButton` поддержан официальный атрибут:
- `style`: `"success"` (зеленый/мятный), `"danger"` (красный/терракотовый), `"primary"` (синий).

## 2. Предлагаемая цветовая палитра по флоу бота
1. **Зеленый (`success`) — Главные целевые действия (Call to Action)**:
   - `[🎬 Сгенерировать видео]` (Главное меню / Баланс)
   - `[🎁 Забрать подарок]` (Подписка на соцсети)
   - `[💳 Оплатить]` / `[✅ Я оплатил]` (Флоу платежа)
   - `[⚡ Создать своё видео]` (Кнопка шеринга)

2. **Синий (`primary`) — Информационные и вспомогательные переходы**:
   - `[💎 Купить генерации]` (Профиль / Меню)
   - `[👥 Поделиться с другом]` (Экран готового видео)
   - `[📺 Опубликовать на YouTube]` (Экран готового видео)

3. **Красный (`danger`) — Отмена и сброс**:
   - `[❌ Отмена]` / `[🚫 Прервать генерацию]`
   - `[🗑 Удалить аккаунт]`

## 3. Регламент внедрения (Safe Rollout)
1. Сначала подготовить тестовую ветку и смоук-тест на Staging (`@meemee_official_bot`).
2. Показать Рику в Telegram живой вид кнопок на Staging для визуального апрува.
3. Только после подтверждения распространить палитру на остальные экраны бота.
