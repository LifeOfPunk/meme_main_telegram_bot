# TASK-15: Единая финализированная спецификация (One-Shot Blueprint)

## 1. Модель баланса и генерация видео
- **AI-модель**: `google/gemini-omni-flash-1-1` (Kie.ai).
  - Параметры: `duration: "6"`, `resolution: "720p"`, `aspect_ratio: "9:16"`.
- **Стоимость видео**: `0.84 USDT` (формула: `BaseCost (0.42) * Multiplier (2.0)`).
- **Списание**:
  - Если `free_quota > 0` -> списывается бесплатная генерация.
  - Если `paid_quota > 0` или `wallet_balance_usdt >= 0.84` -> списывается платная квота / баланс.
  - Если квота и баланс = 0 -> бот пишет:
    *«🎬 Для генерации видео необходимо пополнить баланс»* + кнопка `[💳 Пополнить баланс]`.
