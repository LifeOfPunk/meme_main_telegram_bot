# TASK-15: Кошелек, депозиты от $0.50, автоматический вывод и апгрейд видеомодели

## 1. Бизнес-модель и переход на Wallet Balance
Вместо фиксированных пакетов видео вводится система внутреннего баланса кошелька в долларах (`wallet_balance_usdt`).
- **Стоимость генерации видео**: рассчитывается по динамической формуле:
  `PricePerVideo = BaseCost (0.42 USDT) * Multiplier (2.0) = 0.84 USDT`.
  Коэффициент и базовая цена конфигурируются в переменных окружения.
- При генерации: если `free_quota > 0`, расходуется бесплатная квота; иначе списывается `0.84 USDT` с баланса кошелька.

## 2. Депозиты (Пополнение)
- Сети: TON (Gram), USDT (BEP20), USDT (SOL), BNB (BEP20).
- Минимальный депозит: **0.50 USDT**, максимальный: **10 000.00 USDT**.
- Экран пополнения:
  - Адрес депозита моноширинным текстом `<code>` для копирования в 1 тап.
  - Нативный QR-код (изображение) отправляется вместе с сообщением.
  - Кнопки: `[📋 Скопировать адрес]`, `[✅ Оплачено]`, `[🔙 Назад]`.
- Штучные пакеты видео скрыты из интерфейса.

## 3. Вывод средств (Withdrawal Engine)
- Доступно к выводу: `TotalAvailable = WalletBalance + AffiliateCashback`.
- Минимальная сумма вывода: **5.00 USDT**.
- Сервисный сбор проекта: **2.5%** (`ServiceFee = WithdrawalAmount * 0.025`).
- Сетевая комиссия удерживается с пользователя: `NetPayout = WithdrawalAmount - ServiceFee - NetworkFee`.
- Запрос вывода: ввод адреса и суммы -> валидация баланса и минималки -> автоматическая отправка через 0xProcessing Payout API -> логирование в историю.

## 4. Реферальная система (RevShare)
- Линия 1: **25%** от каждого депозита.
- Линия 2: **10%** от каждого депозита.

## 5. Апгрейд видеомодели на Google Omni Flash 1.1
- Провайдер: Kie.ai
- Модель: `google/gemini-omni-flash-1-1`
- Параметры генерации:
  - `duration: "6"` (6 секунд)
  - `resolution: "720p"`
  - `aspect_ratio: "9:16"`
  - `prompt`: текст промпта пользователя
