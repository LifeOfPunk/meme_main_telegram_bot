# TASK-06: Исследование и внедрение анимированных Telegram Custom Emoji

## 📌 Описание задачи
В современных премиальных ботах (например, @AIVerseXBot) используются живые кастомные анимированные эмодзи прямо в текстах сообщений, заголовках и кнопках. Это сильно повышает воспринимаемое качество продукта (luxury/modern look) и конверсию в действия.

## 🔍 Технические требования Telegram Bot API
1. Telegram позволяет ботам отправлять кастомные анимированные эмодзи при использовании форматирования:
   - **HTML:** `<tg-emoji emoji-id="5368324170671202286">🔥</tg-emoji>`
   - **MarkdownV2:** `![🔥](tg://emoji?id=5368324170671202286)`
2. **Ограничение платформы Telegram:**
   - Бот может отправлять кастомные эмодзи в сообщениях, только если у создателя бота есть Telegram Premium, либо бот привязан к каналу/набору эмодзи, либо бот использует официальные паки Telegram.
   - В тексте самих Inline-кнопок кастомные эмодзи поддерживаются только на клиентах с поддержкой Telegram 9.0+.

## 🛠️ План исследования и реализации
1. Подготовить наглядную визуальную таблицу / превью (как выглядят анимированные эмодзи в интерфейсе @AIVerseXBot vs стандартные Unicode-эмодзи).
2. Выбрать готовый пак эмодзи (Tech / Neon / Gold / Cyberpunk) и извлечь их `custom_emoji_id`.
3. Реализовать хелпер в коде бота для безопасного рендеринга `tg-emoji` с fallback на обычные Unicode эмодзи для старых версий Telegram.

## ✅ Критерии приемки (Definition of Done)
- [ ] Подготовлено превью и список `custom_emoji_id` для согласования.
- [ ] Проверена отправка тестового сообщения с анимированным эмодзи через Telegraf.
- [ ] Бот рендерит анимированные эмодзи в интерфейсе без ошибок парсинга Markdown/HTML.
