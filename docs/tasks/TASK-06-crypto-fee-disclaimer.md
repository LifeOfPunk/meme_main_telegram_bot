# TASK-04: Предупреждение о комиссии биржи (Gate / Binance / Bybit) при выводе крипты

## 📌 Описание проблемы
При оплате через криптовалюту (USDT в сети SOL/TRX/TON) бот выводит точную сумму (например, `Сумма: 6.20000 USDT`). Если пользователь делает вывод напрямую со счета централизованной биржи (Gate.io, Bybit, Binance), биржа автоматически удерживает фиксированную комиссию на вывод (например, 0.5 – 1.0 USDT) **из отправляемой суммы**.
В результате на кошелек мерчанта доходит не $6.20, а $5.70. Платежный шлюз не засчитывает такой платеж как завершенный («Underpaid»), квота пользователю не начисляется, возникают негатив и обращения в поддержку.

## 🛠️ Архитектурное решение (TPM & UX)
Отказываемся от динамического парсинга API бирж (у бирж десятки плавающих тарифов, а интеграция селектора бирж перегружает воронку).

Вместо этого внедряем понятный UX-дисклеймер и удобное копирование:
1. В карточку инвойса добавляем заметный блок с предупреждением:
   ```
   ⚠️ ВНИМАНИЕ: Если отправляете с БИРЖИ (Gate, Bybit, Binance):
   Биржа удерживает комиссию из суммы вывода!
   Указывайте сумму вывода так, чтобы на адрес поступило РОВНО: 6.20000 USDT.
   При недоплате даже $0.10 платеж не зачтется автоматически!
   ```
2. Отдельная кнопка «📋 Скопировать сумму (6.20000)» и «📋 Скопировать адрес».
3. В связке с задачей Binance Pay предлагаем Binance Pay как альтернативу с 0% комиссии.

## ✅ Критерии приемки (Definition of Done)
- [ ] В сообщении с реквизитами для крипто-оплаты присутствует четкое предупреждение о комиссиях бирж.
- [ ] Четко указано требование: сумма фактического поступления должна быть не меньше суммы инвойса.
- [ ] Текст не перегружен и органично смотрится на экранах смартфонов.
