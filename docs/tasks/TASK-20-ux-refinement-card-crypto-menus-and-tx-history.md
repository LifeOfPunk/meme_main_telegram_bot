# TASK-20: Доработка UX бота: очистка текстов, скрытие кнопок оферты, обмен меню и история транзакций

## 📌 Описание задачи и бизнес-контекст
По результатам боевого тестирования интерфейса Риком требуется внести 5 точечных UX-улучшений в Telegram-бота:
1. **Главное меню:** Убрать строку со счетчиком генераций `🔥 Всего генераций в системе: 24,850+`, оставив динамические балансы пользователя.
2. **Экран инвойса карты (Lava):** Скрыть кнопки `📝 Оферта` и `🔒 Политика` (ссылки на них уже встроены в текст инвойса). Оставить только: `💳 Оплатить картой`, `❓ Обратная связь`, `🔙 Назад к пакетам`.
3. **Экран крипто-депозита (0xProcessing):** Убрать громоздкий блок с дисклеймером комиссий бирж (`⚠️ ВНИМАНИЕ: Если отправляете с БИРЖИ...`). Текст сделать лаконичным.
4. **Рокировка меню:**
   - Из Главного меню перенести `❓ Инструкция` в Личный кабинет.
   - Из Личного кабинета поднять кнопку `🤝 Реферальная программа` в Главное меню.
5. **История транзакций:** Добавить в Личный кабинет работающий раздел `💳 История транзакций` на базе `OrderService.getUserOrders(userId)` с отображением статусов (✅ Оплачен / ⏳ Ожидает), сумм и дат.
6. **Восстановление зависших оплат:** Обработать 2 платежа Рика, которые были совершены до исправления 404 на вебхуках.
