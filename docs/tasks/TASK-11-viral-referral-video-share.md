# TASK-11: Вирусный реферальный шеринг видео

## 1. Проблема
При завершении генерации видео кнопка «👥 Поделиться с другом» отправляет через `switch_inline_query` стандартное сообщение без сильного оффера и кликабельной ссылки на бота. Теряется органика и реферальный виральный трафик.

## 2. Требования
1. **Текст сообщения шеринга**:
```markdown
🎬 Смотри, какой вирусный ролик я сгенерировал в ViralApp! 🔥

Забирай бесплатную попытку по моей ссылке и сделай своё видео за 60 секунд:
🚀 https://t.me/viralapp_official_bot?start=ref_{USER_ID}
```
2. **Инлайн-кнопка под отправленным видео**:
   - `[⚡ Создать своё видео]` с прямой ссылкой `https://t.me/viralapp_official_bot?start=ref_{USER_ID}`.
3. **Логика работы**:
   - В `src/bot_start.js` (обработчик `inline_query`) подставлять реферальный ID отправителя в ссылку и caption.
   - Использовать `targetVideo.telegramFileId` для мгновенной отправки видео без повторной загрузки.

## 3. Файлы для изменения
- `src/bot_start.js` (обработчик `inline_query`)
- `src/services/Generation.service.js` (генерация кнопки шеринга)

## 4. DoD
- При клике «Поделиться с другом» формируется карточка с готовым видео, согласованным текстом и кнопкой перехода.
- Реферальная ссылка содержит корректный ID пользователя.
