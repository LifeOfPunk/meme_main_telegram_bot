# TASK-07: Апгрейд генерации видео: замена Grok Imagine на Google Omni Flash + матрица API

## 📌 Описание задачи и бизнес-контекст
Текущая модель Grok Imagine выдает среднее качество видео, не отвечающее ожиданиям аудитории. Ролики в Instagram Рика набирают по 500 000+ просмотров благодаря вирусному высокому качеству генерации. Пользователи, приходящие из Reels/Shorts, ожидают именно ультра-качество кинематографичного уровня.

Цель: перейти на топовую модель генерации (Google Omni 1.1 Flash / Nano / Veo или аналог) с сохранением высокой маржинальности бизнеса.

## 📊 Бизнес-требования к Unit-экономике
Наши розничные тарифы:
- 10 видео: $6.20 ($0.62 / видео)
- 50 видео: $27.90 ($0.558 / видео)
- 100 видео: $52.70 ($0.527 / видео)
- 500 видео: $248.00 ($0.496 / видео)

Себестоимость генерации 1 видео у API-провайдера должна составлять:
- **Целевая себестоимость:** $0.10 – $0.25 за 1 генерацию (маржинальность 60–80%).
- Это оставляет достаточный люфт для скидок, акций, реферальных бонусов и бесплатной генерации при регистрации.

## 🛠️ План исследования
1. **Проверка Kie.ai:**
   - Исследовать официальную документацию и список доступных моделей в Kie.ai API.
   - Проверить наличие `google/omni`, `omni-1.1-flash`, `veo` или топовых альтернатив (Kling 1.5, Luma Dream Machine, Minimax Hailuo).
2. **Если в Kie.ai нет Omni Flash — матрица внешних API:**
   - Собрать сравнительную матрицу провайдеров (Replicate, Fal.ai, Together AI, GoAPI, Vertex AI).
   - Критерии сравнения:
     - Название модели и качество видео (motion consistency, photorealism).
     - Цена за 1 секунду / 1 генерацию (5с или 10с).
     - Latency (время генерации: <60 сек vs очереди).
     - Наличие стабильного REST API и Webhook/Polling.
     - Маржинальность на тарифе $6.20 за 10 видео.
