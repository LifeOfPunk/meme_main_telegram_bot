# TASK-05: Реорганизация меню: перенос кнопок «Обратная связь» и «Приведи друга» в Личный кабинет

## 📌 Описание проблемы
Главное меню бота перегружено второстепенными ссылками («ℹ️ О проекте», «🎁 Приведи друга»), которые отвлекают пользователя от основного целевого действия — генерации и покупки видео. При этом раздел «Обратная связь» спрятан глубоко внутри экрана «О проекте».

## 🛠️ План решения
1. **Главное меню (`src/screens/keyboards.js`):**
   - Оставить только ключевые конверсионные кнопки:
     - `🎁 Бесплатная генерация` (если есть квота)
     - `🎬 Сгенерировать видео`
     - `👤 Личный кабинет`
     - `🎁 Подписывайся за подарок!` (новая механика вместо старого реферала)
   - Убрать из главного меню кнопку «ℹ️ О проекте».
2. **Экран «👤 Личный кабинет» (`profile`):**
   - Перенести внутрь кнопку «💬 Обратная связь / Поддержка» (прямая ссылка на менеджера/бота поддержки).
   - Перенести внутрь кнопку «🎁 Реферальная программа / Приведи друга» (с получением реферальной ссылки и статистики приглашений).

## ✅ Критерии приемки (Definition of Done)
- [ ] Главное меню очищено от лишнего визуального шума.
- [ ] В меню «👤 Личный кабинет» доступны кнопки «💬 Обратная связь» и «🎁 Приведи друга».
- [ ] Переходы между разделами меню работают без ошибок и возвращаются в главное меню.
