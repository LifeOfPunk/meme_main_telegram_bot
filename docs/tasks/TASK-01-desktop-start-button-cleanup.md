# TASK-01: Устранение залипающей Reply-кнопки START в Telegram Desktop

## 📌 Описание проблемы
На клиентах Telegram Desktop (macOS / Windows) после первого вызова `/start` в поле ввода сообщения остается висеть кнопка обычного меню `START`. Она мешает вводу текста и периодически отображается при перемещении по меню, хотя вся навигация бота построена на Inline-кнопках под сообщениями.

## 🔍 Причина
В `src/bot_start.js` при отправке приветственного сообщения новому пользователю передается:
```javascript
reply_markup: {
    keyboard: [[{ text: 'START' }]],
    resize_keyboard: true,
    one_time_keyboard: true
}
```
Флаг `one_time_keyboard: true` поддерживается на мобильных устройствах, но в клиенте Telegram Desktop эта клавиатура не скрывается автоматически и продолжает отображаться внизу чата.

## 🛠️ План решения
1. Заменить приветственную `keyboard` на стандартный Inline-интерфейс, либо при переходе в главное меню отправлять `reply_markup: { remove_keyboard: true }`.
2. Убедиться, что кнопка `START` больше не залипает в поле ввода ни на мобильных, ни на десктопных клиентах.

## ✅ Критерии приемки (Definition of Done)
- [ ] При первом входе в бота поле ввода остается чистым, либо клавиатура удаляется сразу после первого клика.
- [ ] В Telegram Desktop нет висящей кнопки `START` под строкой набора текста.
- [ ] Все переходы в меню продолжают работать через Inline-кнопки.
