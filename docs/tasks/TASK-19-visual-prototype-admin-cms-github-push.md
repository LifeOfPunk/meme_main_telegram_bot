# TASK-19: Визуальная Админка (CMS бота) в прототипе с прямой кнопкой «Push to GitHub»

## 📌 Описание задачи и бизнес-контекст
Рику необходимо оперативно менять тексты экранов бота, названия и порядок кнопок, скрывать кнопки и добавлять новые шаблоны мемов без ручной правки JavaScript-кода.
Решение должно быть реализовано прямо в интерфейсе интерактивного прототипа `https://aiviral.agency/viralapp-telegram-prototype/` с возможностью сохранить изменения и нажать кнопку **«Push to GitHub»**, чтобы автоматически запустился GitHub Actions CD и обновил бота на стейдже.

---

## 🛠️ Архитектура и функционал Админки

1. **Интерфейс Админки (Вкладка «🛠 Админка бота» в прототипе):**
   - **Редактор экранов и текстов:**
     - Редактирование текста экрана 1 (Start/Welcome, статистика генераций).
     - Редактирование инструкций и подсказок.
   - **Редактор кнопок (Keyboards CMS):**
     - Список кнопок каждого экрана.
     - Изменение названия кнопки и callback-действия.
     - Изменение порядка (стрелки ↑/↓).
     - Переключатель видимости (Показать/Скрыть).
     - Добавление новой инлайн-кнопки.
   - **Каталог шаблонов мемов:**
     - Список текущих шаблонов (Мама вызывай, Мопс).
     - Добавление нового шаблона: Название, ID, статус (active/soon), бейдж просмотров, ссылка на видео-превью и статистику, текст промпта.
     - Мгновенный предпросмотр в левом фрейме мобильного телефона.

2. **Механизм «Push to GitHub»:**
   - Поле для ввода GitHub Token (Personal Access Token с доступом к repo) — сохраняется локально в `localStorage` браузера Рика, никуда на внешние серверы не передается.
   - Кнопка **«🚀 Сохранить и запушить в GitHub»**:
     - Формирует обновленный `templates.json` и конфигурацию текстов/кнопок.
     - Через GitHub REST API (`PUT /repos/LifeOfPunk/meme_main_telegram_bot/contents/...`) создаёт коммит в ветку `staging`.
     - Автоматически триггерит воркфлоу `CD Deploy to Staging` в GitHub Actions.
     - Выводит статус деплоя: *«Коммит создан! GitHub Actions обновляет бота...»*.

3. **Связка с рантаймом бота:**
   - Бот считывает шаблоны и тексты из динамического каталога, поэтому изменения сразу применяются после автодеплоя.

---

## ✅ Критерии приемки (Definition of Done)
- [ ] В прототипе доступен режим Админки с редактированием текстов, кнопок и шаблонов.
- [ ] Изменения мгновенно отражаются на макете смартфона в реальном времени.
- [ ] Кнопка «Push to GitHub» создает реальный коммит в ветку `staging`.
- [ ] GitHub Actions автоматически выкатывает обновленный конфиг на стейдж.
