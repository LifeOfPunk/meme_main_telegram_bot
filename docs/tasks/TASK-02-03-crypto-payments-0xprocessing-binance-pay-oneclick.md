# TASK-02 & TASK-03: Крипто-платежи в 1 экран (0xProcessing + Binance Pay)

## 1. Проблема
Сейчас при выборе криптовалюты бот заставляет пользователя сначала выбрать монету (USDT / USDC / TON), а затем на отдельном экране выбирать сеть (TRC20 / BEP20 / Solana). Лишний шаг дробит конверсию.

## 2. Требования к UI/UX (Сокращение воронки)
1. Сразу после выбора пакета («💎 Крипта») открывать **1 экран выбора сети** с 4 готовыми кнопками:
   - `💎 TON (Gram)` -> сеть TON, нативная монета TON
   - `⚡ USDT (BEP20)` -> сеть Binance Smart Chain, токен USDT
   - `🟣 USDT (SOL)` -> сеть Solana, токен USDT
   - `🟡 BNB (BEP20)` -> сеть Binance Smart Chain, нативная монета BNB
2. Кнопка возврата: `[🔙 Назад к пакетам]`.

## 3. Требования к бэкенду и платежному шлюзу
1. В `PaymentCrypto.service.js` связать каждую кнопку с реальным инвойсом 0xProcessing:
   - `TON (Gram)`: `currency: 'TON'`
   - `USDT (BEP20)`: `currency: 'USDT (BEP20)'`
   - `USDT (SOL)`: `currency: 'USDT (SOL)'`
   - `BNB (BEP20)`: `currency: 'BNB (BEP20)'`
2. Генерация QR-кода и прямого deep link на оплату в 1 клик для кошельков (Tonkeeper, Binance, TrustWallet).

## 4. DoD
- Пользователь кликает на монету и сразу получает готовый инвойс с адресом, QR-кодом и таймером без второго экрана.
- Тестовая генерация адреса успешно проходит в 0xProcessing sandbox/live API.
