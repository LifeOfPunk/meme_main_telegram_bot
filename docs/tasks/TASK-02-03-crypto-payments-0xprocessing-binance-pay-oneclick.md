# TASK-02: One-Click оплата криптой в 0xProcessing + интеграция Binance Pay

## 📌 Описание проблемы
1. Сейчас при выборе криптовалюты пользователю предлагается вручную вводить Email в чат Telegram для создания инвойса в 0xProcessing. Это создает лишний барьер воронки (drop-off) и раздражает пользователей.
2. В дашборде 0xProcessing появилась нативная поддержка **Binance Pay**. Binance Pay позволяет пользователям биржи Binance платить мгновенно внутри экосистемы с нулевой комиссией сети и без риска ошибиться в адресе или недоплатить комиссию за вывод.

## 🛠️ План решения
1. **One-Click создание крипто-инвойса:**
   - Исследовать документацию API 0xProcessing (`https://0xprocessing.com`).
   - Проверить возможность передавать системный Email (например, `tg_${userId}@viralapp.agency` или хеш от Telegram ID), если Email является лишь обязательным идентификатором на стороне мерчанта, исключив ручной опрос пользователя в чате.
2. **Интеграция Binance Pay:**
   - Изучить методы API 0xProcessing для генерации Binance Pay ссылки / QR / C2B-платежа.
   - Добавить в меню выбора метода оплаты кнопку «🟡 Binance Pay (0% комиссии)».
   - Проверить вебхук обратного вызова при оплате через Binance Pay и начисление квоты пользователю.

## ✅ Критерии приемки (Definition of Done)
- [ ] При клике на оплату криптой бот не запрашивает ручной ввод Email в чате.
- [ ] Инвойс формируется в 1 клик с QR-кодом и адресом.
- [ ] Добавлена и протестирована опция оплаты через Binance Pay с автоматическим начислением квоты после подтверждения.
