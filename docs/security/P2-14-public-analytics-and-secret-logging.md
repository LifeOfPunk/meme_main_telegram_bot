# P2-14 — Публичная аналитика + логирование секретов

- **Severity:** 🟡 P2 (утечка информации/секретов)
- **Area:** Backend / логирование
- **Status:** OPEN

## Location
- `src/backend/index.js:464-512` — `GET /webhook/analytics/clicks` без аутентификации (воронка, топ-кнопки, кол-во юзеров).
- `src/backend/index.js:120-121` (Lava) и `:303` (crypto) — лог полного тела запроса **и заголовков**, включая `authorization`/`x-signature`.

## Problem
Аналитический эндпоинт открыт без авторизации. Обработчики вебхуков пишут в логи полные заголовки, включая Basic-Auth и подписи.

## Attack / Failure vector
- Публичный сбор бизнес-метрик.
- Секреты (Basic-Auth, подпись) утекают в лог-хранилище/доступ к логам.

## Impact
Разглашение метрик и секретов вебхуков.

## Suggested fix
- Закрыть аналитику авторизацией/внутренней сетью.
- Редактировать `authorization`/`x-signature`/`x-lava-signature` перед логированием; не логировать полное тело в проде.
