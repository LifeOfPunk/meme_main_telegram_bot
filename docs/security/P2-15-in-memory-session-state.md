# P2-15 — Состояние диалога в памяти процесса

- **Severity:** 🟡 P2 (латентный риск устойчивости)
- **Area:** Бот / стейты
- **Status:** OPEN

## Location
- `src/bot_start.js` — `ctx.session` по всему файлу: напр. `:556`, `:765-791`, `:902-988`, `:1275-1302` (`waitingFor: 'name' | 'email' | 'custom_prompt'`).

## Problem
Состояние сцен/ввода хранится в памяти процесса. Оно не переживает рестарт и не разделяется между процессами.

## Attack / Failure vector
Рестарт/масштабирование во время диалога → пользователь «залипает» в состоянии `waitingFor` (ждёт ввод имени/email), поток обрывается.

## Impact
Оборванные пользовательские сессии при рестарте/скейле. Сейчас латентно (один polling-процесс, `USE_WEBHOOK=false`).

## Suggested fix
- Персистить сессии в Redis (напр. telegraf-session-redis), если планируется рестарт-устойчивость или несколько инстансов.
