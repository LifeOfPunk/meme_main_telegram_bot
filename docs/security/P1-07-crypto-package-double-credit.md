# P1-07 — Крипто-пакеты начисляют и генерации, и баланс

- **Severity:** 🟠 P1 (двойная выг: непреднамеренные средства)
- **Area:** Платежи / балансы
- **Status:** OPEN

## Location
- `src/backend/index.js:371-375` — ветка пакета: `addPaidQuota(pkg.generations)` **и** `addWalletBalance(depositAmount)`.
- `src/controllers/paymentController.js:645-648` — то же в ручной проверке.
- Для сравнения фиат: `src/backend/index.js:216-219` — только `addPaidQuota` (без баланса).

## Problem
При оплате криптой фиксированного пакета пользователь получает и генерации пакета, и полную сумму депозита на баланс кошелька. Фиат-ветка для того же пакета начисляет только квоту — поведение несогласованно.

## Attack / Failure vector
Покупатель крипто-пакета осознанно получает квоту + эквивалент суммы деньгами (двойное начисление за один платёж).

## Impact
Прямая финансовая утечка на каждом крипто-пакете.

## Suggested fix
- Единое правило: пакет → только генерации; депозит → только баланс. Убрать `addWalletBalance` из ветки пакета в обоих путях.
